# AirPen

AirPen is a portable Inertial Gesture-Based Air Writing Recognition System that enables users to write in free space using an ESP32-C3 and MPU6050 sensor.

## Features

- Real-time Air Writing
- IMU Motion Tracking
- WiFi Communication
- Deep Learning Recognition
- Touchless Human-Computer Interaction
- Portable Rechargeable Design

## Hardware

- ESP32-C3 SuperMini
- MPU6050
- LiPo Battery
- TP4056 Charger
- Push Buttons

## Software

- Python
- OpenCV
- TensorFlow
- NumPy

## AI

- CNN Handwriting Recognition Model
